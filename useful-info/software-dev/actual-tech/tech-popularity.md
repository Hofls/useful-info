# IT tech popularity

### Programming language
* JavaScript/TypeScript - Almost all frontend in existence is built on that
* Python - For AI, computer science, small-medium scripts (bash replacement)
* Java - King of enterprise backend 
* C# - Microsoft Java
* Go - Cloud-native infrastructure & high-concurrency microservices
* Rust - Modern replacement for C/C++
* PHP - Mostly legacy (WordPress), some modern projects via Laravel

### Database
* PostgreSQL - Simply the best
* MySQL - Classic database
* SQLite - Embedded, zero-config database engine; runs inside mobile apps, browsers and edge runtimes
* MongoDB - King of document-based NoSQL; flexible schema for fast prototyping
* Microsoft SQL Server - Mostly used by enterprise
* Oracle DB - Mostly used by enterprise

### Frontend
* React - Dominant, massive ecosystem and job market
* Angular - Full-featured, batteries-included
* Vue.js - Simple & approachable

### Cloud
* Amazon Web Services (AWS) - №1 by a wide margin
* Google Cloud Platform (GCP) - Strongest for data engineering, AI/ML pipelines, and Kubernetes workloads
* Microsoft Azure - Default for hybrid cloud and Microsoft-centric enterprise tech stacks
* Alibaba Cloud - Mostly popular in Asia

### Message Queue
* Kafka - Distributed event streaming platform, built for massive scale and high-throughput logs
* RabbitMQ - Reliable message broker, flexible routing for asynchronous task queues
* ActiveMQ - Legacy

### Key-Value storage
* Redis - №1 by a wide margin
* Memcached - Simple & performant

### Containers
* Kubernetes - Industry standard for container orchestration
* Docker - Universal tool for containerizing applications and environment standardization

### Coding LLM
* Claude - Consistently tops charts, but very expensive. Agentic tool - Claude Code
* ChatGPT - Consistently tops charts, but very expensive. Agentic tool - Codex
* DeepSeek - Best price to quality ratio. Agentic tool - DeepSeek Harness
* Kimi - Near-top performance for lower cost. Agentic tool - Kimi Code
* Gemini - Middle of the road, okay performance, okay cost. Agentic tool - Gemini CLI

### Desktop app framework
* Electron - Web-tech desktop framework, rich ecosystem, heavy resource usage
* Tauri - Lightweight, secure, and resource-efficient

### Reverse Proxy / Load balancer
* NGINX - Standard load balancer & reverse proxy
* Traefik - Cloud-native edge router
* HAProxy
* Caddy

### CI/CD Tool
* GitHub Action - Industry standard for automated workflows
* GitLab CI - Popular choice for self-hosted DevOps stacks
* Circle CI - Dedicated standalone CI/CD platform

### IDE
* VS Code - Free, lightweight code editor, extensions turn it into full-blown IDE
* IDEs from Jetbrains - Each IDE specializes on a specific language

### Browser Automation
* Playwright - Simply the best
* Selenium - Legacy, but still popular
* Cypress 

### Developer OS
* Windows
* MacOS
* Linux
